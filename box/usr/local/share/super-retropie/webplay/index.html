    Streaming

    This console is too demanding for a browser. Play it by streaming the TV to this device with Moonlight (Windows, Mac, Android and iPhone):

    1. Install Moonlight from moonlight-stream.org and open it - it finds Super RetroPie by itself.
    2. First time only: Moonlight shows a PIN. Enter it at (Sunshine, on the box).
    3. Choose Super RetroPie. You now control the TV's game menu - pick the game there.

    The TV shows the same picture while you stream, so only one person can play.
